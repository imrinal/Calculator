# 💎 AURA — Liquid Glass Universal Computational Engine

A state-of-the-art, ultra-responsive computational platform engineered with Apple Vision Glassmorphism design principles, real-time liquid background dynamics, and multi-engine matrix/financial capabilities.

---

## ✨ Key Technical Highlights

### 🎨 Apple Liquid Glassmorphism Design

* **Glass Physics Backdrop:** Built using non-blocking multi-layered backdrop filters (`blur(35px)` with `saturate(190%)`), dynamic specular border highlights, and ambient floating blurred liquid blobs.
* **Spring Dynamics & Haptics:** Custom `cubic-bezier(0.34, 1.56, 0.64, 1)` spring curves applied to every button interaction with simulated haptic response.
* **Typographic Hierarchy:** Powered by *Plus Jakarta Sans* for chassis aesthetics and *JetBrains Mono* for precision mathematical keying.

### ⚙️ Multi-Engine Computational Modules

1. **Standard Engine:** Everyday arithmetic, inline expression chain evaluation, memory registers (`M+`, `MC`, `MR`), and delete/clear functionality.
2. **Scientific Engine:** Trigonometry ($\sin, \cos, \tan$ with Degree/Radian toggle), Logarithms ($\log, \ln$), Exponents ($x^y, x^2, \sqrt{x}$), Factorials ($n!$), and fundamental constants ($\pi, e$).
3. **Matrix Engine:** Interactive matrix operations ($2 \times 2$ and $3 \times 3$) supporting Addition, Subtraction, Multiplication, Determinant computation, and Matrix Transposition.
4. **Commercial & Financial Suite:** Real-time computation modules for Compound Interest maturity, Loan EMI schedules, GST/Tax addition and removal, and Commercial Profit Margins.
5. **Glass History Register:** Real-time calculation state logger allowing users to inspect past expressions and restore results with a single tap.
